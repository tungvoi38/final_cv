## 3. Kiến trúc và training đã audit

- [train_unet.py](../scripts/train_unet.py) có `build_model()`, `append_sar_delta()`, `loss_fn()`, `step_optimizer()`. [kuro_dataset.py](../scripts/kuro_dataset.py) có `preprocess()`, `normalize_physical_inputs()`, `transform_sample()` và `model_inputs()`.
- A3 là SMP 0.5.0 ResNet-50 U-Net 2D, fully fine-tuned. Input `[B,11,224,224]`, thứ tự pre1 VV/VH, pre2 VV/VH, post VV/VH, DEM, ΔVV/ΔVH, pre-variability VV/VH. `Δ = post − (pre1+pre2)/2`, `variability = abs(pre2−pre1)`, tính trên SAR dB đã z-score và ghép trước encoder. SAR dùng `10 log10(linear power)`, mean VV/VH `[-12.599,-20.293]`, std `[5.195,5.890]`. DEM mean/std `670.665/951.272`. Invalid input điền zero và invalid labels dùng `255`. Output 3 lớp background=0, permanent water=1, flood=2.
- Stem ImageNet 3→7 bằng lặp kernel RGB theo index modulo 3 và scale `3/7`, rồi thêm bốn kernel zero 7→11. Đã kiểm chứng init offline với preset SMP `smp-hub/resnet50.imagenet` revision `00cb74e366966d59cd9a35af57e618af9f88efe9`. Hash weights khởi tạo của run gốc không được lưu riêng.
- Shape encoder theo `C×H×W` là stem `64×112×112`, stages `256×56×56 → 512×28×28 → 1024×14×14 → 2048×7×7`. ResNet bottleneck [3,4,6,3]. Decoder nearest-neighbor, concat bốn skip, hai Conv3×3+BN+ReLU mỗi block. Outputs `256×14×14 → 128×28×28 → 64×56×56 → 32×112×112 → 16×224×224`. Head duy nhất Conv1×1 16→3 có bias. Dummy forward xác nhận shape và **32.546.099 trainable parameters** (23.533.120 encoder, 9.012.928 decoder, 51 head), **8.450.441.216 convolution MACs/patch**.
- Training chung của run nguồn gồm CE + multiclass soft Dice (1:1, smoothing 1), AdamW (encoder LR 3e-5, decoder/head 1e-4, WD 0.01), cosine theo optimizer update (`T_max=40000`), AMP/GradScaler, clip norm 1, D4 train-only, SAR noise tắt. `event_sqrt` dùng `1/sqrt(n_event)` và replacement. Batch 2, 4.000 draws/epoch, 20 epoch. Actual updates tới epoch 20 theo seed 42/43/44 là 39.982/39.981/39.982.
- Source run ghi Python 3.12.3, torch 2.8.0+cu126, CUDA 12.6, SMP 0.5.0, RTX A5000. HEAD ghi `0db9983b4c3eb3e551e7c6e7570ba8aff35ea9cc`. Loader tại commit này có SHA `276521132cd3b2c24e03b13ab84ba92b3d1efcc439dd0490b0db1dd303452c50` khớp run nguồn. Trainer lúc train có SHA `e8e93b3501eaac53c6d69cdd8441f544d990c20f13230e2c9abc5c39d1bf1d11`. Trainer lúc eval bắt đầu `9302ecc2`. Các trainer hashes và bản SMA lúc train không tìm thấy bản byte-identical trong Git objects cục bộ. Kiến trúc/state_dict đã được kiểm chứng. Exact retraining và phiên bản TorchVision lịch sử chưa xác minh.

## 7. Điểm kiểm tra khi tiếp quản

- Nếu tiếp tục viết paper, kiểm tra mỗi con số có đúng checkpoint recipe, split, patch count, bias lock và metric convention. Dùng thuật ngữ **Vanilla ERM**, **best-SMA EoA + Flip +0.95**, hoặc **fixed-epoch-20 EoA + Flip** theo đúng artifact.
- Khi cần audit thêm, tái dùng logits hoặc confusion matrix trước. AP dùng flood margin `z_flood − max(z_background,z_water)`, gom exact ties, non-interpolated AP. Pooled metrics gom confusion matrix, event-macro cho mỗi event một trọng số, IoU std dùng `ddof=0`. Paired bootstrap resample toàn event và dùng chung draw cho hai phương pháp.
- Nếu một kết quả mới cần test, xác định trước protocol và lock. Oracle hoặc historical test không điều chỉnh model, checkpoint, threshold, ensemble weights hay cấu hình. Chưa có bằng chứng matching exact historical trainer snapshot hoặc completion đầy đủ LOEO. Đánh dấu các giới hạn đó khi báo cáo.
